# Lifetime

独立的演员制作与演出预览工具。只有演员（Actors）与场景（Play），采用浅色三栏界面，默认进入场景。

## 启动

需要 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5190。资源服务自动运行在 5191。

页面启动后优先自动打开地图库中的“中式园林9”，并载入它最近保存的场景与 NPC。其他地图仍可从左上角切换；没有园林时打开首个可用地图。

```sh
npm test
npm run build
npm start
```

构建后，`npm start` 在 http://127.0.0.1:5191 同时提供页面和资源接口。不需要 WorldForge、Voxel Studio 或其他兄弟项目。

## 使用

- **进入地图**：地图预览右上角点击“进入”，以钢铁侠鸭子的第三人称视角游玩。WASD 移动、空格跳跃，鼠标拖动转视角、滚轮缩放；点击“退出”或按 Esc 返回编辑。复用演员库中的模型与奔跑动画，真实后端生成的“玩家·跳跃”保存在“红金钢铁侠装甲鸭”的动画库中。进入不再调用生成后端，也不保存临时玩家位置；控制实现见 [玩家控制](docs/player-controls.md)。
- **Actors**：左上角展开演员切换器，新建演员；生成模型后，进入动画制作，生成并播放动画。模型重新生成后形成新版本，已有动画保留原版本绑定。右侧模型／动画／动作三个页签用于制作；支持暂停、复位、进度拖动和循环。
- **动作制作**：左侧动作库新建动作。点击地图标点的 ＋ 创建 p1、p2，拖到预览地面定位（也可点击“放置”后点击地面）；离地高度大于 0 即为空间点。将点拖进文本框、点击“引用”或输入 @ 引用，然后输入要求、生成、用中央播放按钮预览并保存。直接使用当前模型的动画库，无需动画池。程序控制接口见 [运动接口文档](docs/motion-api.md)。
- **Play**：从左上角的地图选择器打开地图，自动载入最近保存的场景。左侧显示 NPC 列表，选中 NPC 后，下方显示其状态网络和完整动作；点击状态查看对应配置，点击动作查看地图位置绑定。右侧“NPC 设置”提供行为与位置编辑，在“位置”中放置 P 点、调整站位和通行能力；NPC 列表旁的 ＋ 可加入演员。中央播放整个场景，并显示所选 NPC 的动作进度。保存修改可恢复配置，旧演出在地图选择器的“历史版本”中打开。源动作修改后需“更新动作引用”；旧内嵌动作显式归入演员库后才编辑绑定。详情见 [地图动作接口](docs/scene-motion.md)。
- **角色状态机**：一个状态执行一个完整动作。例如“绕池塘跑步”与“跑到桥中央、面向池塘、跳舞后空翻并返回”是两个状态。设置执行次数、等待与后续状态，即可循环切换；选择自身可持续重复。中央统一播放／暂停整个场景，复位返回设计位置；行为卡片默认收起，展开后设置完整动作、次数和后续行为。切换保留真实站位，规则随演出保存，整个流程本地运行。详情见 [状态机接口](docs/character-machine.md)。
- **修改地图路径**：选中 NPC 和动作，点击左侧状态机旁的“修改路径”，同时显示该动作的 P 点和蓝色 NavMesh 实际导航路线。拖动后自动重新计算，切换动作更新对应路线；显示／隐藏同时控制点和路线，不丢弃编辑。不可达时清除旧路线并显示原因。点击“保存路径”保存当前场景并在下次播放时重新寻路；点击“取消”恢复原点位。编辑时暂停场景，点位暂存于独立草稿，保存失败可重试；切换 NPC 或地图会放弃未保存的路径草稿。共用同一 P 点的动作也会采用修改后的位置。
- **一句话构建场景**：Play 打开地图或演出后，在右侧“场景”输入要求、点击“生成场景”（已有角色时显示“修改场景”）。AI 根据地图摘要规划角色、所需动画和完整行为；本地服务复用已有素材、并发生成缺失模型与动画，浏览器自动寻找 P 点、计算 NavMesh、制作并绑定完整动作，保存新演出后可播放。右侧按角色显示每项模型、动画的状态及生成描述，完成后可查看模型或预览动画。继续输入修改要求可生成新版本，保留未涉及角色；失败时保留已完成素材，可重试单项或继续装配。详情与程序端口见 [自动生成](docs/scene-generation.md)。
- 导入独立渲染方案时，先打开目标地图；会保存为新的地图资源，不覆盖旧地图。含外部资源引用的地图应从原 WorldForge 导出完整场景 ZIP。缺少模型或 HDRI 的包会明确报错。
- 地图导入与导出在左上角的地图选择器中。导出为可重新导入的 `.lifetime-scene.zip`，包含地图、渲染方案及嵌入的 HDRI；NPC 实例和状态规则另存于场景配置。
- 工作区切换保留当前数据与任务，只让活动工作区持续渲染。保存失败可重试保存已有生成结果；取消请求只是停止等待，后端任务可能继续执行。

演员层手动生成通过浏览器访问后端；场景自动生成由 Lifetime 本地服务调用后端。需要更换地址时，复制 `.env.example` 为 `.env`，设置 `VITE_GENERATION_API` 后重启开发服务；发布构建需重新 build。自动生成默认沿用 VITE_GENERATION_API，也可通过 LIFETIME_GENERATION_API 单独配置本地服务；更改后重启服务。该变量不是密钥存储位置。

运行数据位于本项目 `data/actors`、`data/maps`、`data/performances`，不提交 Git。普通任务和未保存草稿保存在浏览器内存中；刷新前应完成保存。自动生成任务、指导文档和待保存结果保存在 data/builds，本地服务运行时关闭页面仍继续生成素材；重新打开地图后可继续装配。服务重启后结果未知的远端请求不会自动重发。浏览器 localStorage 仅保存装配续存记录，模型与动画不写入浏览器存储。

地图动作当前支持静态地面寻路、完整到达和已有动画组合；不包含地图生成/编辑、Stage、独立长动画生成、环境互动、动态避让、物理/IK 或 NPC agent。动作规划器只生成结构化计划，运动执行器不逐帧调用 AI。当前动画播放器处理骨骼姿态，不提供粒子/VFX 动画制作；不支持的数据明确报错。

开发规则见 [AGENTS.md](AGENTS.md)，架构见 [docs/architecture.md](docs/architecture.md)，验证记录见 [docs/verification.md](docs/verification.md)。
