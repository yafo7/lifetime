# 地图语义与本地区域求解

规划器读取精简地图目录，输出 `featureId + relation`。浏览器结合真实几何、角色通行配置与静态 Recast NavMesh 求解位置。参考 Voxel Engine 的候选区域和本地执行分工，代码为 Lifetime 独立实现，没有复制该项目模块或增加运行依赖。

## 地图目录

`semanticIndex.ts` 从水域、引导线、名称和资源标签建立地标，包含建筑、桥、树及可识别的井、农田、长椅、围栏等。`aliases` 保存源资源别名；`sector` 是九宫格方位，north对应-Z。`near` 使用包围盒间距，只表示空间邻近，不承诺道路连通。

摘要最多96项，优先主要地标，超出时返回 `omittedFeatures`；邻近引用仅指向本摘要。未列物体仍参与导航，但规划器不能引用。几何、坐标、模型节点和 NavMesh 不发送给 chat。名称分类不是视觉识别，`queries` 只表示可尝试，不是已验证可达。

## 求解与导航

1. 将关系转为有界区域，查询重叠 NavMesh 多边形，分别保留各高度层。自适应网格加多边形代表点覆盖区域和狭窄通道。
2. 按语义范围、高度和水域筛选，并先覆盖不同连通区域。将候选重新锚定到真实表面，验证法线、支撑层和严格投影。
3. 结合语义距离、实际路径长度和起点选择。起点优先连接后续移动目的地；无法同时满足时，后续地点和动作仍分别报告问题。
4. 引导线和环路使用动态规划联合选点，包括接入和闭合返回边；选中后用执行使用的完整 `route()` 复核连续支撑，失败边排除后有限重选。
5. 冻结为可编辑 P 点，交给已有完整动作、状态及衔接检查。只保存意图和选中点，不保存采样网格、派生路径或运行时钟。

`Navigation.pathLength()` 用完整走廊作评分，拒绝部分路径；`route()` 提供实际地面高度。角色半径、高度、坡度和台阶限制保持不变，不把不可达终点替换为远处可达点。

## 查询边界

- `near`：在包围盒外搜索，距离为角色半径+0.35至此距离+6，并要求接近地面层。地面查询覆盖整张地图。
- `shore`：按实际水岸线段距离查找水外地面。
- `center`：搜索中央40%宽深区域，小模型在自身边界内至少尝试0.6宽深。桥要求自身表面。建筑搜索低处地板，高度上限为建筑底部与中央地形较高者，加 `max(1.5, climb+0.2)`，并受模型高度限制；不以屋顶或建筑外替代，不提供任意楼层选择。
- `alongGuide`：保留有效转折，每站最多水平偏移0.65，联合寻找连通支撑点，最多20站。
- `surroundingRoute`：按实际水岸凸包外扩并有限尝试边距，超过10个凸包顶点使用保守包围矩形。实际路线须不入水、不跨水岸，并围住全部岸线顶点。复杂凹岸或贴边障碍仍可能需要人工补点。
- `facing`：只用于朝向，不要求站立。

预算为区域8192多边形、约384次候选表面复核、最多64个有效候选、路线每站前8候选、严格路线失败最多重选32轮。超预算报告 `REGION_SEARCH_LIMIT`；查询失败表示在当前区域和预算中未找到解，不是任意地图可达性的数学证明。

## 诊断与恢复

`LOCATION_UNSUPPORTED` 表示地点/查询无效；`NO_STANDING_SURFACE` 表示未找到满足角色配置的支撑；`TARGET_UNREACHABLE` 表示有站位但路线不连通；`CIRCUIT_UNREACHABLE` 表示无完整干燥环路；`REGION_SEARCH_LIMIT` 表示搜索预算不足。

单点失败保留真实候选；路线失败保留各站建议及闭合属性，缺失支撑的站点保留原意图位置。这些是待修复建议，不作为可执行路线发布。已有素材、成功动作和人工修改继续使用原有构建检查点；手动位置不被自动覆盖。

固定回归见 `tests/spatialRegions.test.ts`，真实地图只读验证见 `verification.md`。本轮没有调用真实生成服务。
