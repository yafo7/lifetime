# 地图第三人称游玩

在地图预览右上角点击“进入”。编辑侧栏收起，中央保留地图、角色和操作提示；按钮变为“退出”。WASD 相对镜头方向移动，空格单次跳跃，鼠标拖动旋转镜头，滚轮调整距离，Esc 退出。切换到演员工作区也会退出。地图原有 NPC 可继续执行状态机。

## 资源与实例

- `play/playerAssets.ts` 从 Actors 中选择红金钢铁侠装甲鸭，按同一模型版本解析奔跑与跳跃动画；不跨模型版本混用，不复制模型，也不在进入时生成资源。缺失素材会明确提示。
- 本轮复用模型 `e0e52da7-57ac-4cf4-bae9-728662413a19` 和“原地奔跑循环”。新增“玩家·跳跃” `fbbd95dd-f90c-453b-a42d-8996b5cb1aeb`，时长 1.1 秒，保存在演员 `9840550d-5029-48de-af56-333d69e5eed9` 下，包含完整动画及后端响应。
- 玩家只作为当前预览的临时实例加入 Viewport；不进入 NPC 列表，不写入演出、地图或源演员的配置。退出释放模型实例和事件，恢复原编辑镜头。资源仍统一由演员库管理。

## 执行边界

`PlayWorkspace` 负责资源解析、获取共用地图几何与 NavMesh、选择安全出生点和进入/退出。出生点优先使用地图出生区域，避开已有 NPC；局部区域不可行走时在地图内搜索有效地面，找不到则停止进入。

`play/playerMotion.ts` 仅处理位置、朝向和跳跃，不读取 DOM 或调用网络。NavMesh 的 `moveAlongSurface` 将每次短距离移动限制在当前连通表面，并沿障碍边缘滑动；不使用最近点投影把玩家传送过障碍。位置按小步积分，斜向输入归一化。跳跃使用本地抛物线、重力、头顶检查及落地检测，空中不能二次起跳。

`rendering/thirdPersonControls.ts` 负责输入与跟随镜头，使用地图几何检查镜头遮挡。失去焦点或页面隐藏时清空按键，避免粘键。`Viewport` 采样待机/奔跑/跳跃姿态并短暂混合；动画的根位移不驱动玩家碰撞位置，跳跃姿态随本地跳跃进度采样。后端完整动画保留原样，Actors 独立预览仍使用原始轨道。

当前水平移动（包括跳跃时）受静态 NavMesh 限制；没有游泳、跨越不可通行区域、攀爬、推物体或 NPC 动态碰撞。新增这些能力时应扩展本地控制器与导航，而不是让 AI 逐帧控制角色。

## 2026-10-14 后端契约核对

实时读取 `https://voxel-studio-backend.zeabur.app/api/docs/api-reference` 的 §5.0/5.1，沿用共用生成客户端：

```json
POST /api/generate/animation
{
  "modelJson": "Actors 当前模型的完整 JSON 对象",
  "description": "单次跳跃关节姿态，控制器负责根节点水平和垂直位移，不生成特效",
  "provider": "gpt",
  "mode": "quick",
  "emitParticles": false
}
```

成功响应为 `{ "ok": true, "baked": { "fps": 60, "duration": 1.1, "loop": false, "animation": { ... } } }`。位置轨道是相对初始局部位置的增量，旋转轨道为弧度；四元数轨道存在时优先使用。时长使用后端值，不在请求中固定。

本轮按用户授权真实调用一次，要求普通蹬地、收腿、展翼平衡、落地恢复，禁止翻转、飞行、根节点平移或特效。返回结果先在本地缓存，经过 `decodeAnimation` 校验后，通过演员资源接口入库。游玩不依赖生成服务持续在线。
